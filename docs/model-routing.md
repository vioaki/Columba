# 原生模型聚合与调度

模型以原始模型 ID 和原生协议作为唯一身份；显示名称不参与匹配。支持 `openai`、`responses`、`claude`、`gemini`，跨协议渠道隔离。渠道及模型均启用时成为候选，不以生成式健康探测结果隐藏模型。

模型调度设置保存在业务库 `settings` 的 `model-routing:` 条目中，默认等权轮询、最多额外重试 3 次、间隔 1000 ms。优先级数值越小越优先；加权使用平滑加权轮询，每个渠道默认权重为 1。重试使用完整的候选渠道与有效 Key 列表，每个组合只出现一次。凭据来自当前渠道，不使用模型行的历史密钥快照。

调度器仅给出候选顺序；发送后的重试边界由原生 HTTP 透传路径负责。核心覆盖精确身份、禁用源和 Key、并发轮询、权重比例、优先级、持久化及非法设置。
